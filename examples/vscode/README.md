# Hone Protocol — VS Code / GitHub Copilot Integration

GitHub Copilot reads `.github/copilot-instructions.md` for custom instructions.

## Setup
```bash
npx hone init --target vscode
```
This creates `.github/copilot-instructions.md` with the Hone Protocol.

## Manual Setup
Create `.github/copilot-instructions.md` and paste the contents of `hone.md` into it.

---

## Notes for VS Code users
- The Copilot instructions file applies to Copilot Chat in VS Code
- Copilot inline completions (autocomplete) are not affected — only Chat
- For full Hone coverage, use Cursor or Claude Code where the protocol applies to all interactions
